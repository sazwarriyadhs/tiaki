# TIAKI

## Halal Slaughter Intelligence

New Zealand focused digital intelligence platform for halal slaughter,
meat processing, assurance, evidence, traceability and export intelligence.

### Core Principle

TIAKI helps halal meat businesses operate:

- Faster
- More efficiently
- More transparently
- More traceably
- With stronger halal assurance

TIAKI does not replace:

- MPI
- Approved Halal Organisations
- Auditors
- Veterinarians
- Religious authorities
- Legal/regulatory decision makers

AI provides intelligence and attention signals.
Final halal, regulatory and operational decisions remain with authorised humans.

## Core Traceability

Animal

→ Post-Mortem
→ Carcass
